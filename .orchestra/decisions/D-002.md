# D-002: Event-Driven Skill Plugin Architecture

## Decision
Each general's skills are independent TypeScript modules that register event listeners. The engine fires events (damage, play card, phase change, etc.) and skills respond via a priority-ordered listener chain.

## Rationale
341 generals with unique skills require a scalable, testable architecture. Event-driven plugins allow each skill to be developed and tested independently. QSanguosha uses a similar trigger-based system (Lua).

## Alternatives Considered
- Hardcoded skill logic in a giant switch: unmaintainable at 341 generals
- Inheritance-based: creates deep coupling between skills
