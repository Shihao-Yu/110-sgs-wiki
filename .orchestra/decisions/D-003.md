# D-003: QSanguosha as Primary Rule Reference

## Decision
Use QSanguosha (太阳神三国杀) source code as the authoritative reference for game rules, skill implementations, card effects, and AI logic. Our engine reimplements in TypeScript but must produce identical game behavior.

## Rationale
QSanguosha has years of community testing and is the de facto standard for digital Sanguosha. Reimplementing from scratch would introduce rule ambiguities.

## Alternatives Considered
- Official rulebook only: ambiguous on many skill interactions
- Custom interpretation: would diverge from community expectations

T-014, T-021-T-0210, T-031-T-073, T-081-T-082, T-111
