# D-001: TypeScript Full-Stack Monorepo

## Decision
Use TypeScript throughout with pnpm workspaces monorepo: packages/data, packages/engine, packages/ai, packages/web.

## Rationale
Engine must run in both Node.js and browser (isomorphic). Shared types across all packages reduce integration bugs. Single language simplifies tooling.

## Alternatives Considered
- Python backend + React frontend: better AI/stats ecosystem but loses isomorphic engine
- Mixed: more complexity in build/deploy

## Affected Tasks
T-011, T-021, T-091
