# Sprint Contract: T-011 — Monorepo setup

## Planner Context
- Product slice: Project foundation — pnpm monorepo with 4 TypeScript packages (data, engine, ai, web)
- Why now: Every other task depends on this. It's the root of the dependency graph.

## Generator Proposal
- User-visible outcome: A working monorepo where `pnpm install` and `pnpm build` succeed across all 4 packages
- Files / interfaces to touch: package.json (root), pnpm-workspace.yaml, tsconfig.json (root + per-package), packages/{data,engine,ai,web}/package.json, packages/{data,engine,ai,web}/tsconfig.json, packages/{data,engine,ai,web}/src/index.ts
- Verification plan: `pnpm install` → `pnpm build` → `pnpm test` (should run with 0 tests)
- Risks / open questions: Next.js in packages/web needs special tsconfig; engine must be isomorphic

## Evaluator Gate
- Required acceptance criteria: pnpm install succeeds, pnpm build succeeds across all packages, Vitest configured
- Required verification commands: `pnpm install`, `pnpm build`
- Required falsification target: Try importing from packages/engine in packages/web — cross-package imports must work
- Rubric dimensions in play: Scope Fidelity, Functionality, Quality/Craft, Integration Safety
- Hard thresholds: Scope ≥ 4, Functionality ≥ 4, Integration ≥ 4

## Final Contract
- Scope locked: monorepo setup only — no business logic, no data, no UI
- Done means: `pnpm install && pnpm build` succeeds, all 4 packages exist with tsconfig, Vitest configured
- Out of scope: game logic, data schemas, UI components, actual tests
- Contract status: approved
